## `01 // PROJECT OVERVIEW`

Welcome to my **Week 2 Cybersecurity Project!**

This project focuses on practical cybersecurity activities involving Footprinting, Open-Source Intelligence (OSINT), DNS Enumeration, Web Technology Fingerprinting and Network Scanning.

The practical exercises were performed using Kali Linux and Oracle VirtualBox.
